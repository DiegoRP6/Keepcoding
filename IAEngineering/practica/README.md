# Pokemon GO Raid Advisor

Practica Diego Rodriguez de AI Engineering KEEPCODING.

Agente ReAct hecho con LangChain que ayuda a planear raids de Pokemon GO consultando la PokeAPI.

## Archivos

- `pokemon_raid_advisor.ipynb`: notebook principal.
- `tools.py`: las dos tools que consultan la PokeAPI.
- `evaluation.py`: casos de prueba.

Modelo utilizado: gpt-5-mini.
