# Frontend — Clinical Intelligence Platform

SPA construida con **React + TypeScript + Vite + TailwindCSS**.

## Estructura

```
src/
├── components/   # Componentes reutilizables
├── pages/        # Páginas
└── services/     # Llamadas a la API
```

## Desarrollo local

```bash
npm install
cp .env.example .env
npm run dev
```
